# Assignment #2 - Advanced CSS

This project contains the practical tasks for the Advanced CSS assignment about Flexbox and CSS Grid.

## Pages

- `index.html` - project start page
- `task0.html` - Flexbox navigation bar
- `task1.html` - Flexbox card row
- `task2.html` - page layout using CSS Grid areas
- `task3.html` - nine-image CSS Grid gallery with hover captions
- `task4.html` - portfolio page combining Flexbox and CSS Grid
- `style.css` - shared styles for all pages

## How to run

Open `index.html` in a browser.

## Publishing

The project can be published with GitHub Pages or Netlify. For GitHub Pages, upload all files to a repository, open repository Settings, choose Pages, select the branch containing the project, and save.
